# 🧪 Photosynthetic Bacteria (PSB) Liquid Bottle Inspector & Classifier
> **แอปพลิเคชันเว็บตรวจสอบและจำแนกขวดจุลินทรีย์สังเคราะห์แสงด้วย Computer Vision (HSV) และเชื่อมต่อ ThaiLLM (Pathumma 3.0)**

## 🎯 1. วัตถุประสงค์ของโครงการ (Project Goal & Theme)
แอปพลิเคชันนี้ถูกพัฒนาขึ้นเพื่อช่วยให้เกษตรกรและผู้ผลิตปุ๋ยชีวภาพสามารถตรวจสอบคุณภาพและความพร้อมใช้งานของ **จุลินทรีย์สังเคราะห์แสง (Photosynthetic Bacteria: PSB)** ในขวดบรรจุของเหลวได้อย่างแม่นยำ รวดเร็ว และเป็นวิทยาศาสตร์:
* **การจำแนกสถานะความพร้อม (Classification):**
  * **✅ พร้อมใช้งาน (Ready to Use):** ของเหลวมีสีแดงเข้ม / แดงเลือดนก / แดงอมม่วง (Burgundy) ซึ่งแสดงถึงความหนาแน่นสูงของแบคทีเรีย *Rhodopseudomonas palustris* และสารรงควัตถุชีวภาพ (Bacteriochlorophyll และ Carotenoids)
  * **⏳ ยังไม่พร้อมใช้ / อยู่ระหว่างการหมัก (Not Ready / Still Fermenting):** ของเหลวเป็นสีขาวขุ่น / ใส / ชมพูจาง / เหลืองอำพัน
* **คำแนะนำจากผู้เชี่ยวชาญ (AI Agricultural Advisor):**
  * เชื่อมต่อไปยัง **ThaiLLM API (Pathumma 3.0)** เพื่อให้คำแนะนำที่ปรับแต่งตามผลการตรวจ (เช่น อัตราส่วนผสมน้ำสำหรับฉีดพ่นพืชแต่ละชนิด เทคนิคการตากแดด และการระบายแก๊ส)
  * ระบบมี **ฐานความรู้ผู้เชี่ยวชาญเกษตรอินทรีย์ออฟไลน์ (Offline Bio-Expert)** สำรองในกรณีที่ไม่ได้ระบุ API Token หรือเซิร์ฟเวอร์ขัดข้อง

## ⚙️ 2. สถาปัตยกรรมและการประมวลผลภาพ (Core Features)

### 2.1 Computer Vision & HSV Color Space Analysis
1. **การแปลงพื้นที่สี:** แปลงภาพถ่ายจาก RGB เป็น **HSV (Hue, Saturation, Value)**
2. **การตรวจจับเม็ดสีแดง-ม่วง (Red/Magenta Pigment):**
   * ค่า Hue ของสีแดงจะคร่อมรอยต่อ 0 และ 180 ใน OpenCV:
     * สีแดงช่วงล่าง: $H \in [0, 14]$
     * สีแดงอมม่วง/บานเย็น: $H \in [150, 179]$
   * กรองสีขาว/น้ำใส ด้วย Saturation ($S \ge 45$)
   * กรองเงามืดและฝาขวดสีดำ ด้วย Value ($V \ge 30$)
3. **การกำหนดพื้นที่วิเคราะห์ (Region of Interest - ROI):**
   * **🎯 แกนกลางของเหลว (Liquid Center Focus):** วิเคราะห์พื้นที่ช่วง 20% ถึง 80% เพื่อหลีกเลี่ยงขอบขวด ฝาขวด และพื้นหลัง
   * **🖼️ ทั้งภาพ (Full Image):** วิเคราะห์ภาพรวมทั้งหมด
   * **📐 กำหนดกรอบพิกัดเอง (Custom ROI):** ผู้ใช้สามารถเลื่อน Slider ปรับตำแหน่งการตรวจได้อย่างอิสระ
4. **เกณฑ์การตัดสินใจ (Thresholding):**
   * คำนวณร้อยละของพิกเซลเม็ดสีแดงต่อพื้นที่ของเหลว ($\text{Red Pigment Ratio} = \frac{\text{Red Pixels}}{\text{Total Liquid Pixels}} \times 100\%$)
   * หากค่าที่ได้ $\ge \text{Threshold}$ (ค่าเริ่มต้น 25.0%) $\rightarrow$ จัดเป็น **"พร้อมใช้งาน (Ready to Use)"**

### 2.2 ThaiLLM API Integration (Pathumma 3.0)
* **API Endpoint:** `http://thaillm.or.th/api/v1/chat/completions`
* **Model:** `pathumma-thaillm-qwen3-8b-think-3.0.0`
* **ระบบความปลอดภัย:** รองรับการกรอก Bearer Token ผ่านแถบ Sidebar และรองรับการดึงค่าจาก `.streamlit/secrets.toml`
* **Thinking Parser:** คัดแยก `<thought>...</thought>` ออกมาแสดงในกล่องขั้นตอนการคิด เพื่อให้คำแนะนำหลักอ่านง่าย

## 🚀 3. วิธีการติดตั้งและเริ่มใช้งาน (Installation & Run)

### 3.1 ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### 3.2 ตั้งค่า API Key (ไม่บังคับ)
สร้างหรือแก้ไขไฟล์ `.streamlit/secrets.toml`:
```toml
THAILLM_API_KEY = "your-thaillm-bearer-token-here"
```
*(หากไม่ใส่ สามารถกรอกผ่านหน้าเว็บในแถบ Sidebar ได้ หรือใช้งานคำแนะนำออฟไลน์ได้ทันที)*

### 3.3 รันแอปพลิเคชัน
```bash
streamlit run app.py
```
เปิดเบราว์เซอร์ที่: `http://localhost:8501`

## 📊 5. ตารางระยะการบ่มหมักและการนำไปใช้งาน

| ระยะ (Stage) | ลักษณะสีของน้ำ | สัดส่วนเม็ดสีแดง | สถานะ | การนำไปใช้ |
| :--- | :--- | :---: | :---: | :--- |
| **Stage 0: เริ่มต้น** | ขาวขุ่น / ใสอมเหลือง | < 5% | ⏳ ยังไม่พร้อมใช้ | ตากแดดจัด 6-8 ชม. เขย่าขวดวันละ 1-2 ครั้ง |
| **Stage 1: เริ่มมีสี** | ชมพูอ่อน / ส้มจาง | 5% - 15% | ⏳ บ่มหมัก | เซลล์เริ่มสร้างรงควัตถุ คลายฝาระบายแก๊สหากขวดบวม |
| **Stage 2: สีเข้มขึ้น** | แดงส้ม / แดงสด | 15% - 25% | ⏳ บ่มหมัก | เซลล์ทวีคูณอย่างรวดเร็ว ตากแดดต่ออีก 7-10 วัน |
| **Stage 3: สมบูรณ์** | แดงเข้ม / ไวน์แดง | > 25% | ✅ **พร้อมใช้งาน** | ผสมน้ำ 1:1,000 ฉีดพ่นใบ หรือ 1:500 รดโคนต้น |
